# User Guide: Managing Family Notes

## Creating Notes
1. Navigate to the **Notes** page.
2. Tap the blue **(+)** button at the bottom right.
3. Add a **Title** (e.g., Grocery List) and the **Content**.
4. Tap **Save**.

## Organizing Notes
- **Pinning**: Tap the **Pin** icon on a note to keep it at the top of the screen.
- **Categories**: You can categorize notes (Shopping, Personal, Family) to filter them.
- **Search**: Use the search bar at the top to find notes quickly.

## Editing & Deleting
- Tap on any note card to open the editor.
- Admins and members can delete any note using the trash icon in the editor view.
